# Ismail Rajhi — 3D Portfolio

Interactive 3D developer portfolio for **Ismail Rajhi**, Computer Science graduate & Master's student in Computer Science. Built with Three.js, TypeScript, and a retro CRT workstation experience embedding **IsmailOS**.

<br>

To setup a dev environment:

```bash
# Clone the repository

# Install dependencies 
npm i

# Run the local dev server
npm run dev
```

To serve a production build:

```bash
# Install dependencies if not already done - 'npi i'

# Build for production
npm run build

# Serve the build using express
npm start
```
